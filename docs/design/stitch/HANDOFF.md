# NextBill 안드로이드 UI 디자인 검토 및 개발 전달 가이드 (Handoff Guide)

- **기준 문서**: `stitch-prompts.md` 및 `docs/superpowers/specs/2026-10-23-nextbill-design.md` §9
- **디자인 시스템**: `NextBill Clean Fintech` (Android Material 3 / Material You 기반)
- **대상 플랫폼**: Android Mobile (390dp 기준 반응형, Material You 토큰 대응)

---

## 1. 프로젝트 디자인 총평 및 핵심 원칙

NextBill은 **토스(Toss) 스타일의 친숙하고 정갈한 한국형 핀테크 감성**과 **Android 14+ Material 3 가이드라인**을 융합한 로컬 온디바이스 구독 관리 앱입니다.

1. **온디바이스 신뢰성 (On-Device Privacy)**
   - 별도 로그인 없이 기기 내부 로컬 DB에만 데이터를 영구 보관합니다.
   - 설정 화면 및 빈 상태 안내 문구에 자물쇠 아이콘과 함께 신뢰 보증 텍스트를 일관되게 노출합니다.
2. **시각적 계층 구조 (Visual Hierarchy)**
   - **숫자 중심 시각화**: 월 총 결제 예정액과 주요 금액은 대형 볼드 타이포그래피로 명확히 인지되도록 처리.
   - **신호등 원칙의 컬러 사용**: 일반 상태는 브랜드 딥 블루(`#1b64da`) 위주로 차분함을 유지하고, 결제 당일(`오늘`)과 익일(`내일`)에만 소프트 레드 긴급 칩 배지를 적용하여 불필요한 시각적 노이즈를 억제.
3. **이니셜 아바타 시스템 (Letter Avatar)**
   - 외부 브랜드 로고 저작권 이슈를 피하고 일관된 통일감을 주기 위해, 서비스명의 첫 글자를 딴 원형 컬러 아바타(8가지 프리셋 컬러)를 규격화.

## 2. 전체 8+1 화면 디자인 명세 및 화면별 검토 내역

### [화면 0] 홈 (대시보드) — `NextBill — 홈 (대시보드)`
- **주요 역할**: 월별 총 지출 예정액 요약 확인, 결제 임박순 정렬 리스트 탐색, 신규 구독 진입.
- **주요 컴포넌트**:
  - `TopAppBar`: "NextBill" 볼드 워드마크 + 우측 설정(아이콘) 버튼.
  - `SummaryCard` (16dp Corner Card):
    - 상단 "이번 달 결제 예정 (5월)" + "내역보기 >"
    - 볼드 금액 `₩86,400`
    - 보조 지표: "월 고정비 ₩72,300", 외화 결제 "+ $19.98" 병기.
  - `UpcomingList`: 날짜순 정렬 필터 칩, 6종 샘플 구독(넷플릭스, 통신비, 유튜브, iCloud+, 헬스장, 자동차보험).
  - `M3 FAB`: 하단 우측 고정 `+ 구독 추가` (Extended FAB 스타일로 높은 클릭 타깃 확보).
  - `BottomNavBar`: 홈 / 캘린더 / 설정 3개 목적지 탭.

### [화면 1] 홈 (빈 상태) — `NextBill — 홈 (빈 상태)`
- **주요 역할**: 앱 최초 실행 시 또는 모든 구독 삭제 시 맞이하는 온보딩 유도 상태.
- **주요 컴포넌트**:
  - 요약 카드는 음영 처리된 `₩0`과 함께 "등록된 고정비가 아직 없어요" 표시.
  - 중앙 Empty 카드: 영수증 심볼 배지 + "등록된 구독이 없어요" + 전면 `+ 첫 구독 추가하기` Primary CTA 버튼.
  - 하단 정보 팁: 전구 아이콘과 "모든 데이터는 기기에만 안전하게 보관돼요" 배치.

### [화면 2] 구독 등록·수정 — `NextBill — 구독 등록·수정`
- **주요 역할**: 신규 정기 결제 항목 등록 및 기존 항목 상세 수정.
- **주요 컴포넌트 & 인터랙션**:
  - 실시간 아바타 프리뷰 (이름 첫 글자 및 선택 색상 반영).
  - 큰 금액 입력창 + 통화 셀렉터 드롭다운 (`KRW ▾`, USD 등 다중 통화 지원).
  - 유효성 검증 에러 상태 시각화 (`0원 이상의 결제 금액을 입력해주세요` 레드 헬퍼 텍스트).
  - 주기 선택 스텝퍼 (`- 1 +`) 및 세그먼트 버튼 (`일 / 주 / 개월 / 년`) + 주기 계산 헬퍼 텍스트.
  - Material DatePicker 트리거 필드 ("첫 결제일").
  - 가로 스크롤 카테고리 칩 (영상, 음악, 통신, 보험, 클라우드, 생활, 기타).
  - 8가지 테마 색상 팔레트 라디오 스와치.
  - 결제 알림 설정: 토글 스위치 + 사전 알림 일수 선택 칩(`당일`, `1일 전`, `3일 전`, `7일 전`) + 시각 설정.

### [화면 3] 구독 상세 (넷플릭스) — `NextBill — 구독 상세 (넷플릭스)`
- **주요 역할**: 개별 구독의 세부 정보 확인, 환산 고정비 파악, 해지 및 영구 삭제 처리.
- **주요 컴포넌트**:
  - 상단 대형 이니셜 아바타 + 서브 카테고리 태그(`영상`) + 정기 결제 주기.
  - 비용 분석 요약: **월 환산 금액**(`₩17,000`), **연 환산 금액**(`₩204,000`), 알림 설정 요약.
  - 향후 다가오는 결제일 타임라인 (D-Day 배지와 함께 3회차 사전 일정 제시).
  - 메모 카드 (예: "스탠다드 요금제 4K 지원").
  - 액션 그룹: `해지 처리`(Outlined Button, '해지한 구독'으로 보관) 및 `삭제`(Error Red Text Button, 영구 제거).

### [화면 4] 해지한 구독 — `NextBill — 해지한 구독`
- **주요 역할**: 과거 이용했으나 해지된 구독 항목 보관 및 간편 복원 지원.
- **주요 컴포넌트**:
  - 상단 알림 배너: "해지한 구독은 합계와 알림에서 제외돼요".
  - 리스트 아이템: 채도가 빠진 그레이톤 아바타, 해지 일자 표기.
  - 오버플로 메뉴 드롭다운: `다시 사용`(원래 설정 그대로 복원) / `완전 삭제`(DB 영구 삭제).
  - 하단 재등록 안내 팁 카드.

### [화면 5] 설정 — `NextBill — 설정`
- **주요 역할**: 기본 알림 기준, UI 테마, 데이터 백업/복원 및 오픈소스 정보 관리.
- **구조**:
  - **알림**: 기본 알림 시점(1일 전), 기본 시각(오전 9:00), 시스템 알림 권한 상태 칩(`허용됨`).
  - **화면**: 테마(시스템 설정 / 라이트 / 다크), Material You 동적 색상 스위치.
  - **기본값**: 기본 통화(`KRW (₩)`).
  - **데이터**: 백업 파일 내보내기/가져오기 (JSON 포맷 권장), 해지한 구독 진입 링크.
  - **정보**: 오픈소스 라이선스 고지, 버전 정보(`1.0.0`).

### [화면 6] 홈 화면 위젯 (4×2, 2×2) — `NextBill — 홈 화면 위젯 (4×2, 2×2)`
- **규격**: Android Glance / RemoteViews 기반 Material 3 위젯.
- **4×2 와이드 위젯**: 이 달의 총액, 새로고침 버튼, 결제 임박 구독 3개 리스트 + 퀵 등록 버튼.
- **2×2 컴팩트 위젯**: 가장 가까운 결제 1건(넷플릭스) 집중 노출.

### [화면 7] 알림 권한 안내 시트 — `NextBill — 알림 권한 안내 시트`
- **규격**: Material 3 Modal Bottom Sheet.
- **구성**: 상단 드래그 핸들, 중앙 벨 아이콘 배지, 마케팅 스팸 미발송 안심 안내, `알림 허용하기` CTA 및 `나중에` 버튼.

### [화면 8] 홈 대시보드 (다크 모드) — `NextBill — 홈 (대시보드 다크 모드)`
- **서피스 레벨**: `#121316`(배경), `#1c1e22`(카드 컨테이너), 고대비 화이트 금액 텍스트.
- **다크 전용 칩**: 과도한 눈부심을 막는 소프트 레드 틴트 컨테이너로 야간 시인성 확보.

## 3. 개발 전달(Handoff) 및 토큰 매핑 가이드

### A. 색상 토큰 (Color Tokens)
| 토큰명 | 라이트 모드 | 다크 모드 | 용도 |
| :--- | :--- | :--- | :--- |
| `color-primary` | `#1b64da` | `#82b1ff` | Primary 버튼, FAB, 활성 탭, 주요 강조 |
| `color-surface` | `#f8f9fb` | `#121316` | 최상위 화면 배경 |
| `color-surface-container` | `#ffffff` | `#1c1e22` | 기본 콘텐츠 카드 (16dp 라운드) |
| `color-surface-dim` | `#f2f4f6` | `#282a2f` | 입력창 배경, 비활성 칩 배경 |
| `color-text-primary` | `#191f28` | `#f5f6f8` | 대형 금액, 주요 헤드라인 |
| `color-text-secondary` | `#4e5968` | `#a6adb8` | 본문, 보조 설명 라벨 |
| `color-text-tertiary` | `#8b95a1` | `#6b7684` | 플레이스홀더, 비활성 탭, 타임스탬프 |
| `color-warning-urgent` | `#f04452` | `#ff6b76` | 오늘/내일 결제 긴급 배지 텍스트 |
| `color-warning-container`| `#feecee` | `#3d1a1e` | 긴급 배지 배경 컨테이너 |

### B. 라운드 및 여백 (Shapes & Spacing)
- **카드 모서리**: `16dp` (`rounded-2xl`)
- **버튼 / 칩**: `12dp` (입력 필드, 버튼) 및 `9999dp` (Pill 모양 카테고리 칩)
- **바텀 시트 상단**: `28dp` (`rounded-t-[28dp]`)
- **그리드 패딩**: 좌우 기본 `20dp` 마진, 컴포넌트 간 세로 간격 `12dp` / `16dp`

### C. Jetpack Compose 구현 추천 사항
- **통화 포맷팅**: `NumberFormat.getCurrencyInstance(Locale.KOREA)` 기본 적용. 외화인 경우 `$9.99` 등 해당 통화 심볼과 분리 저장.
- **백업 구조**: SQLite / Room DB 스키마를 단일 암호화되지 않은 JSON 파일로 내보내기/가져오기 할 수 있는 `DataBackupRepository` 권장.
- **위젯 구현**: Jetpack Glance 라이브러리를 사용하여 Compose 문법으로 4×2, 2×2 위젯 동기화.
