# ADR-0009: 금액은 최소 단위 `Long`

- 상태: 승인 (2026-10-23)
- 출처: 설계 문서 §4.1, §6 ADR-9 [설계자 판단]

## 맥락
금액 합계와 월 환산은 이 앱의 핵심 출력입니다. 부동소수점으로 계산하면 오차가 생깁니다. 지원 통화(KRW, USD, EUR, JPY)는 소수 자릿수가 서로 다릅니다.

## 결정
- 금액은 통화의 최소 단위 정수(`Long`, 원·센트)로 저장하고 계산합니다. `Money(minor: Long, currency: CurrencyCode)`.
- 통화별 소수 자릿수는 `java.util.Currency.defaultFractionDigits`를 씁니다.
- `Double`/`Float`로 금액을 계산하지 않습니다. 합산은 `Math.addExact`로 해서 넘침을 조용히 넘기지 않습니다.
- 월 환산처럼 나눗셈이 있는 계산은 정수 최소 단위로 하고, 반올림 규칙(HALF_EVEN)을 한 곳에서 정의합니다.
- 통화가 여러 개면 통화별로 따로 합산하고 환산하지 않습니다.

## 대안
- **`Double`/`Float`:** 부동소수점 오차가 생깁니다.

## 결과
- 입력 문자열 → 최소 단위 변환과 표시 형식은 통화의 소수 자릿수에 따라 달라지므로 따로 테스트합니다.
- 합산이 `Long` 범위를 넘으면 `ArithmeticException`이 납니다. 조용히 틀린 합계를 보여 주지 않기 위해서입니다.
