# ADR-0005: 알림 권한은 알림을 켤 때 묻고, 의도와 수신 가능 여부를 나눕니다

- 상태: 승인 (2026-10-23), 2차 리뷰(2026-10-24) 반영
- 출처: 설계 문서 §6 ADR-5 [설계자 판단]

## 맥락
- Android 13+는 `POST_NOTIFICATIONS` 런타임 권한이 필요합니다.
- 앱 실행 직후 요청하면 거부율이 높습니다. 저장 뒤에 물으면 화면이 이미 닫혀 있습니다.
- 사용자가 알림을 켜 두어도 권한, 앱 알림 차단, 채널 차단 때문에 실제로는 받지 못할 수 있습니다.

## 결정
- 알림 스위치를 켤 때, 또는 알림이 켜진 구독을 **저장하기 직전에** 요청합니다. 권한 요청은 `ActivityResultContracts`로 직접 구현합니다(accompanist 금지).
- 구독의 알림 설정(사용자 의도)과 실제 수신 가능 여부(권한·앱 알림 차단·채널 차단)를 나눠 다룹니다.
- 요청 이력은 **OS 권한 요청을 실제로 띄웠을 때만** DataStore에 기록합니다. 안내 시트의 "나중에"는 기록하지 않습니다.
- 앱 복귀 때 상태를 다시 확인합니다. 받을 수 없으면 상세·설정 화면에 "알림을 받을 수 없어요"와 설정 이동을 보여 줍니다.

## 대안
- **앱 첫 실행 때 요청:** 맥락 없이 물어 거부율이 높습니다.
- **저장한 뒤 요청:** 화면이 닫힌 뒤라 결과를 보여 줄 곳이 없습니다.
- **요청 이력을 화면 세션에만 보관:** 화면을 다시 열면 이력이 사라집니다(2차 리뷰 지적).

## 결과
- 알림 설정이 켜져 있어도 받을 수 없는 상태를 화면에 드러냅니다.
- 처음 알림을 켤 때의 설명 시트(설계 문서 §9-7)가 필요합니다.
