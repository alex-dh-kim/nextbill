# ADR-0001: 서버·네트워크 없음, `INTERNET` 권한 미선언

- 상태: 승인 (2026-10-23)
- 출처: 설계 문서 §2.2, §6 ADR-1 [Alex 결정]

## 맥락
NextBill이 다루는 것은 구독 이름, 금액, 결제일 같은 개인 금융 데이터입니다. "금융 데이터는 기기 밖으로 나가지 않는다"를 설계 원칙으로 정했고, 이 원칙은 말이 아니라 저장소에서 확인할 수 있어야 합니다.

## 결정
- 서버, 로그인, 동기화를 만들지 않습니다. 모든 데이터는 기기 안(Room, Preferences DataStore)에만 저장합니다.
- `AndroidManifest.xml`에 `android.permission.INTERNET`을 선언하지 않습니다. 네트워크 라이브러리(Retrofit, OkHttp, Coil, Firebase)도 쓰지 않습니다.
- 예외는 사용자가 직접 고른 경우뿐입니다. 백업 파일을 내보낼 때 사용자가 클라우드 문서 앱을 저장 위치로 고르면 그곳에 저장됩니다. README에 이 차이를 씁니다.

## 대안
- **서버 동기화:** 기기 간 동기화가 생기지만 데이터가 기기 밖으로 나갑니다. v1 범위 밖입니다(설계 문서 §2.4). Repository 인터페이스 뒤에 붙일 수 있는 확장 지점만 문서로 남깁니다.
- **권한은 선언하되 쓰지 않기:** 원칙을 증명할 수 없습니다. 권한이 없다는 사실 자체가 증거입니다.

## 결과
- 빌드한 APK의 `aapt2 dump permissions` 결과에 `INTERNET`이 없어야 합니다(Task 1 Step 5에서 확인).
- 클라우드 자동 백업도 같은 원칙에 맞춰 끕니다(ADR-0008).
- 원격 이미지·분석·크래시 리포팅을 쓸 수 없습니다. 서비스 로고 대신 이름 첫 글자 + 색상 아바타를 씁니다.
