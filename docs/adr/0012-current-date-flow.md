# ADR-0012: 오늘 날짜를 Flow로 제공합니다(`CurrentDateSource`)

- 상태: 승인 (2026-10-23), 1차 리뷰(2026-10-24) 반영
- 출처: 설계 문서 §4.2 오늘 날짜, §6 ADR-12 [설계자 판단]

## 맥락
`Clock`은 값을 읽을 때만 쓰입니다. 홈·캘린더를 켠 채 자정이나 월말을 넘기거나 시간대를 바꾸면 "오늘", D-n, 이번 달 합계가 그대로 남습니다.

## 결정
- 오늘 날짜를 `Flow`로 제공하는 `CurrentDateSource`를 둡니다.
- 날짜 변경·시간 변경·시간대 변경 브로드캐스트와 앱 복귀(`ProcessLifecycleOwner`) 때 새 값을 방출합니다.
- 모든 화면은 이 값으로 재계산합니다. 시간은 주입한 `Clock`과 `CurrentDateSource`에서만 얻고, `LocalDate.now()`/`System.currentTimeMillis()`를 인자 없이 부르지 않습니다.

## 대안
- **`Clock`만 주입:** 테스트에서 날짜를 고정할 수는 있지만 켜 둔 화면이 날짜 변경을 모릅니다.
- **분 단위 폴링:** 쓰지 않습니다. 필요한 순간은 날짜·시간·시간대 변경과 앱 복귀뿐입니다.

## 결과
- 화면 상태는 Room `Flow` + 오늘 날짜 `Flow`를 합쳐 계산합니다.
- 가짜 `CurrentDateSource`로 "화면을 켠 채 월말 자정 통과", "앱 복귀 때 날짜 변경", "시간대 이동"을 테스트합니다(설계 문서 §8).
