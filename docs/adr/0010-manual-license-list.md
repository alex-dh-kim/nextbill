# ADR-0010: 오픈소스 라이선스 화면은 직접 관리하는 목록으로 만듭니다

- 상태: 승인 (2026-10-23)
- 출처: 설계 문서 §6 ADR-10 [설계자 판단]

## 맥락
앱이 쓰는 오픈소스 라이브러리의 라이선스를 고지해야 합니다. Google oss-licenses 플러그인은 목록을 자동으로 만들어 주지만 Play 서비스 의존성을 추가합니다.

## 결정
- 라이선스 목록은 `res/raw`에 직접 관리합니다. Google oss-licenses 플러그인은 쓰지 않습니다.
- **직접 의존하는** 라이브러리 목록과 버전 카탈로그(`gradle/libs.versions.toml`)가 어긋나지 않는지 테스트로 검사합니다.
- 전이 의존성(AndroidX 등)은 묶어서 한 줄로 고지합니다.

## 대안
- **oss-licenses 플러그인:** 자동이지만 Play 서비스 의존성이 추가됩니다. 네트워크 없는 최소 의존 원칙(ADR-0001, 설계 문서 §1.2-3)과 맞지 않습니다.

## 결과
- 직접 의존성을 추가하면 라이선스 목록도 함께 고쳐야 하고, 빠뜨리면 테스트가 실패합니다.
- 전이 의존성은 개별 고지하지 않고 묶음 한 줄로 다룹니다. 범위를 README에 적습니다.
